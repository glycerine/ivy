# C9: TYPE with Range — InterpretDecl and UninterpretedSort Substitution

**Created:** 2026-03-24T23:30

## Context

The Go grammar rule `p_top_type_symbol_eq_sort` (`grammar_v17.y:1031-1043`) creates a `TypeDef` with the raw sort value, regardless of whether the sort is a `Range`. The Python source of truth (`ivy_parser.py:1780-1797`) has three additional behaviors when the sort is a `Range`:

1. **Replaces the sort with `UninterpretedSort()`** in the TypeDef — the type becomes uninterpreted
2. **Creates an `InterpretDecl`** with `Implies(scnst, range)` wrapped in a `LabeledFormula` with label "interp"
3. **Checks `optghost` ($3)** to use `GhostTypeDef` instead of `TypeDef`

Go does none of these. This is audit item C9 from `LALR_AUDIT.md`.

## Python Source of Truth

```python
# ivy_parser.py:1780-1797
def p_top_type_symbol_eq_sort(p):
    'top : top optfinite optghost TYPE typesymbol EQ sort'
    p[0] = p[1]
    scnst = Atom(p[5])
    scnst.lineno = get_lineno(p,5)
    defsort = UninterpretedSort() if isinstance(p[7],Range) else p[7]
    tdfn = (GhostTypeDef if p[3] else TypeDef)(scnst,defsort)
    if p[2]:
        tdfn.finite = True
    tdfn.lineno = get_lineno(p,6)
    p[0].declare(TypeDecl(tdfn))
    if isinstance(p[7],Range):
        imp = Implies(scnst,p[7])
        imp.lineno = get_lineno(p,4)
        thing = InterpretDecl(addlabel(mk_lf(imp),'interp'))
        thing.lineno = get_lineno(p,4)
        p[0].declare(thing)
```

Grammar positions: `top(1) optfinite(2) optghost(3) TYPE(4) typesymbol(5) EQ(6) sort(7)`

### Note on GhostTypeDef assignment

There's a subtlety: when `$3` is true (ghost), the variable `tdfn` is declared as `*ast.TypeDef`. The `GhostTypeDef` embeds `TypeDef`, so we need to handle this carefully. Two options:

**Option A**: Use `tdfn` as the embedded TypeDef:
```go
var tdfnNode ast.Node
if $3 {
    td := ast.TypeDef{Name: scnst, Value: sortNode}
    tdfnNode = &ast.GhostTypeDef{TypeDef: td}
} else {
    tdfnNode = &ast.TypeDef{Name: scnst, Value: sortNode}
}
// Need to set Finite on the TypeDef inside whichever variant
```

**Option B** (simpler): Build TypeDef first, then wrap:
```go
tdfn := &ast.TypeDef{Name: scnst, Value: sortNode}
if $2 { tdfn.Finite = true }
tdfn.SetLineno(tokLineno(lex, $6))
var tdfnNode ast.Node = tdfn
if $3 {
    tdfnNode = &ast.GhostTypeDef{TypeDef: *tdfn}
}
td := ast.NewTypeDecl(tdfnNode)
$$.declare(td)
```

**Option B is cleaner** — build the TypeDef, set all fields, then conditionally wrap in GhostTypeDef. This avoids any issues with accessing Finite through the wrapper.
