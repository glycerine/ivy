# Plan: Comprehensive M10 (lineno_add_ref) + L3 (ivyAccum as ast.Node) Port

**Created:** 2026-03-25T04:30

## Context

Two tightly related issues remain in the LALR parser port:

1. **M10**: `lineno_add_ref` system not ported — `SetReferenceLineno` is dead code because no Clone/rewrite methods read it. Also `doInsts` doesn't pass lineno to `instMod`.

2. **L3**: Object tracking lost because Go converts module body `ivyAccum` → `Sequence(decls...)`, discarding the `.objects`, `.defined`, `.static`, `.modules`, `.macros`, `.actions` maps. Python stores the `Ivy` class instance directly as the module body RHS in `Definition(name, ivy_instance)`.

The user has decided: **make `ivyAccum` implement `ast.Node`** to match Python's architecture, where `Ivy` is a pseudo-AST-node stored directly in `Definition.Rhs`.

```go
// LinenoAddRef wraps a location with the current reference lineno.
// Matches Python lineno_add_ref (ivy_ast.py:19-22).
func LinenoAddRef(loc Location) Location {
    if referenceLineno == (Location{}) {
        return loc
    }

        Line:      referenceLineno.Line,
        Reference: &refCopy,
```

### A6. Base `AST.clone` equivalent — NOTE on scope

Python's base `AST.clone()` (ivy_ast.py:30-36) calls `lineno_add_ref`. However:
- **Atom.clone** and **App.clone** in Python do NOT call `lineno_add_ref` — they don't copy lineno at all
- Instead, `copy_attributes_ast_ref` in `ast_rewrite` handles Atom/App lineno
- The base `AST.clone` applies to types that inherit directly from AST without overriding clone
- In Go, `AstRewrite`'s default case calls `x.Clone(newArgs)` which copies `Base` directly

The Go `AstRewrite` default case (`rewrite.go:705-711`) handles non-specific types by calling `x.Clone(AstRewriteSlice(args, rewrite))`. The Clone methods for most types copy `Base` directly (which includes Loc). Since these types are not Atom/App/Variable/WhenOperator, they don't go through `CopyAttributesAstRef`.

**Decision:** For the default/generic Clone path, we should NOT add `LinenoAddRef` to every Clone method — Python only applies it in specific places (AST.clone base, WhenOperator.clone, Variable.resort, copy_attributes_ast_ref). The key coverage points are:
- A3: CopyAttributesAstRef — covers Atom/App during AstRewrite
- A4: Variable.Resort — covers Variable during AstRewrite
- A5: WhenOperator.Clone — covers WhenOperator

For other types that go through AstRewrite's default path, Python's base `AST.clone()` applies `lineno_add_ref`. In Go, we need to add `LinenoAddRef` in the default case of AstRewrite:

**File:** `ast/rewrite.go:705-711`
```go
default:
    if args := x.Args(); args != nil {
        newArgs := AstRewriteSlice(args, rewrite)
        res := x.Clone(newArgs)
        res.SetLineno(LinenoAddRef(x.GetLineno()))  // ADD THIS
        return res
    }
    return x
```

## Part B: L3 — ivyAccum Implements ast.Node

### B1. Add ast.Node interface methods to ivyAccum

**File:** `lalr_full/ivy_module.go`

Python's `Ivy` class has (ivy_parser.py:393-406):
```python
@property
def args(self):
    return []
def clone(self, args):
    return self
def rewrite(self, rewrite):
    if isinstance(rewrite, AstRewriteSubstPrefix):
        res = Ivy()
        inst_mod(res, self, None, rewrite.subst, dict())
        return res
    return self
```

Go implementation:
```go
// --- ast.Node interface for ivyAccum ---
// Python's Ivy class IS stored as module body in Definition(name, ivy_instance).
// Ivy.args returns [], Ivy.clone returns self, Ivy.rewrite has special handling.

func (m *ivyAccum) Args() []ast.Node { return nil }

func (m *ivyAccum) Clone(args []ast.Node) ast.Node { return m }

func (m *ivyAccum) GetLineno() ast.Location { return ast.Location{} }
func (m *ivyAccum) SetLineno(loc ast.Location) {}

func (m *ivyAccum) String() string {
    return fmt.Sprintf("<ivyAccum decls=%d>", len(m.decls))
}

func (m *ivyAccum) Canon() iu.Canonical {
    // Module body appears as the RHS of a Definition inside ModuleDecl.
    // Python's Ivy doesn't have canon() — for cross-language comparison,
    // emit the decls as a sequence.
    return iu.Canonical(fmt.Sprintf("(ivy decls:%s)", ast.SliceCanon(m.decls)))
}
```

**Note on Canon():** Need to export `sliceCanon` from `ast` as `SliceCanon` (it's currently unexported). Or add a helper.

**Note on Rewrite:** Python's `Ivy.rewrite()` is special — when encountered during `AstRewriteSubstPrefix`, it creates a new Ivy and calls `inst_mod`. In Go's `AstRewrite`, this means we need a special case for `*ivyAccum` (or the Rewrite interface approach). However, since `ivyAccum` is in `lalr_full` and `AstRewrite` is in `ast`, we can't add a case in `AstRewrite`'s switch.

**Solution:** Add an `AstRewritable` interface to `ast`:
```go
// AstRewritable is implemented by types that need custom rewrite behavior.
// Python: hasattr(x, 'rewrite')
type AstRewritable interface {
    Rewrite(rewrite AstRewriter) Node
}
```

In `AstRewrite`'s default case, check for `AstRewritable` BEFORE the generic `Args()` fallback:
```go
default:
    if rw, ok := x.(AstRewritable); ok {
        return rw.Rewrite(rewrite)
    }
    if args := x.Args(); args != nil {
        ...
    }
```

This matches Python's `ast_rewrite` which checks `hasattr(x, 'rewrite')` before the generic `args` fallback (ivy_ast.py:1731-1733):
```python
if hasattr(x,'rewrite'):
    return x.rewrite(rewrite)
```

Then implement `Rewrite` on `ivyAccum`:
```go
func (m *ivyAccum) Rewrite(rewrite ast.AstRewriter) ast.Node {
    if sp, ok := rewrite.(*ast.AstRewriteSubstPrefix); ok {
        res := newIvyAccum(m.parent, "")  // no global state — pass parent explicitly
        instMod(res, m, nil, sp.Subst, nil, "")
        return res
    }
    return m
}
```

**Wait — type visibility issue:** `AstRewriteSubstPrefix` is in `ast`, `instMod` is in `lalr_full`. The `Rewrite` method on `ivyAccum` is in `lalr_full`, so it CAN access both. The `AstRewritable` interface is in `ast`. This works.

But there's a subtlety: `instMod` currently takes `bodyDecls []ast.Node`. After B3, it will take `*ivyAccum`. So in `Rewrite`, we pass `m` directly. Good.

### B7. Port `define()` method fully

**File:** `lalr_full/ivy_module.go:71-76`

Current stub:

Python `ivy_parser.py:351-366`:
```python
def define(self, df, allow_redef=False):
    if len(df) == 3:
        name, lineno, cls = df
    else:
        name, lineno = df
        cls = None
    for x in self.defined[name]:
        olineno, ocls = x[0], x[1]
        conflict = ((ocls is not ObjectDecl) if cls is TypeDecl
                    else (ocls is not TypeDecl) if cls is ObjectDecl else True)
        if conflict:
            if allow_redef:
                return
            report_error(Redefining(name, lineno, olineno))
    self.defined[name].append((lineno, cls))
```

Go — need to change `define` signature to accept structured data. Python's `decl.defines()` returns list of tuples `(name, lineno)` or `(name, lineno, cls)`. Go's `Defines()` returns `[]string` (names only).

**Approach:** Add a new method `DefinesRich()` to declaration types that returns `[]DefineEntry`:
```go
type DefineEntry struct {
    Name     string
    Lineno   ast.Location
    DeclType string  // "TypeDecl", "ObjectDecl", "DestructorDecl", or ""
}
```

Then `define()` becomes:
```go
func (m *ivyAccum) define(entry DefineEntry) {
    xtracer.Trace("parser.define ENTER")
    if m.defined == nil {
        m.defined = make(map[string][]definedEntry)
    }
    for _, x := range m.defined[entry.Name] {
        conflict := true
        if entry.DeclType == "TypeDecl" {
            conflict = (x.DeclType != "ObjectDecl")
        } else if entry.DeclType == "ObjectDecl" {
            conflict = (x.DeclType != "TypeDecl")
        }
        if conflict {
            // report_error(Redefining(...)) — error reporting
            return
        }
    }
    m.defined[entry.Name] = append(m.defined[entry.Name], definedEntry{
        Lineno:   entry.Lineno,
        DeclType: entry.DeclType,
    })
}
```

```python
    if defined is not None:
        defined = defaultdict(list, ((k, v.copy()) for k, v in defined.items()))
```

```go
func setObjectDefined(ivy *ivyAccum, name string, moduleDefined map[string][]definedEntry) {
    xtracer.Trace("parser.set_object_defined ENTER")
    if moduleDefined != nil {
        // Deep copy: Python's defaultdict(list, ((k,v.copy()) ...))
        copied := make(map[string][]definedEntry, len(moduleDefined))
        for k, v := range moduleDefined {
            entryCopy := make([]definedEntry, len(v))
            copy(entryCopy, v)
            copied[k] = entryCopy
        }
        moduleDefined = copied
    }
    if entries, ok := ivy.defined[name]; ok {
        for i := range entries {
            entries[i].ObjectDefined = moduleDefined
        }
        ivy.defined[name] = entries
    }
}
```
