# Plan: Fix CompiledNode Canon Divergence in Schema Bodies

**Created:** 2026-03-26T22:00

## Context

`make golden` (TestOrdLive) fails at line 79344 because Go's schema body canon output contains `(compiledNode )` placeholders where Python has fully-resolved nodes. The divergence is in the `schemata` hash for `rec[index]`:

**Go produces:**
```
elems:[(compiledNode ) (constantDecl  declArgs:[(compiledNode )] ...) ... (compiledNode )]
```

**Python produces:**
```
elems:[(UninterpretedSort name:q) (constantDecl  declArgs:[(Symbol name:base sort:(FunctionSort ...))] ...) ... (Def lhs:... rhs:...)]
```

Two bugs cause this:

1. **`CompiledNode.Canon()` is opaque** — it emits `(compiledNode )` ignoring the `Node` field, which actually holds `lg.Expr` values that have `Canon() iu.Canonical` methods.

2. **TypeDef premise returns wrong type** — Go wraps in `lg.NewSymbol(name, sort)` but Python returns the `UninterpretedSort` directly.

## Fix 1: Make CompiledNode.Canon() delegate to inner node

**File:** `ast/ast.go:1534-1536`

The `Node` field holds `interface{}` but in practice stores `lg.Expr` types, all of which implement `iu.Canonizer` (i.e., `Canon() iu.Canonical`). The `ast` package already imports `iu`, so no new imports needed.

Change:
```go
func (c *CompiledNode) Canon() iu.Canonical {
    return iu.Canonical(fmt.Sprintf("(compiledNode %v)", c.Base.canonFields()))
}
```

To:
```go
func (c *CompiledNode) Canon() iu.Canonical {
    if cz, ok := c.Node.(iu.Canonizer); ok {
        return cz.Canon()
    }
    return iu.Canonical(fmt.Sprintf("(compiledNode %v)", c.Base.canonFields()))
}
```

This delegates to the inner node's `Canon()` (which calls `Sexp()` for logic types), matching Python's behavior where compiled nodes are directly serialized.

## Fix 2: TypeDef premise returns sort, not symbol

**File:** `compiler/phase6.go:1193-1199`

Python `compile_schema_prem` for TypeDef:
```python
elif isinstance(self,ivy_ast.TypeDef):
    t = ivy_logic.UninterpretedSort(self.args[0].rep)
    sig.sorts[t.name] = t
    return t     # Returns the sort itself
```

Go currently:
```go
case *ast.TypeDef:
    sort := &lg.UninterpretedSort{Name: name}
    schemaSig.Sorts[name] = sort
    return &ast.CompiledNode{Node: lg.NewSymbol(name, sort)}, nil  // WRONG: wraps in Symbol
```

Change to:
```go
case *ast.TypeDef:
    sort := &lg.UninterpretedSort{Name: name}
    schemaSig.Sorts[name] = sort
    return &ast.CompiledNode{Node: sort}, nil  // Store the sort directly, like Python
```
