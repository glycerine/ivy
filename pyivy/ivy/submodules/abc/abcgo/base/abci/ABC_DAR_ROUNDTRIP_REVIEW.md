# ABC Dar round-trip source review

Reviewed against `src/base/abci/abcDar.c`:

- `Abc_NtkFromCellMappedGia` preserves the C literal-indexed copy table (`2*ObjId + phase`), PI/PO and RI/RO ordering, constant creation for constant COs and buffers, cell-fanin order, paired positive/negative inverter handling, barrier-buffer marking, output connection order, dummy names, and `LogicMakeSimpleCos(1-fUseBuffs)`. The Go backing array is initialized to `-1`, matching `Vec_IntStartFull`; the mapper library and root-cell records come from the active ABC frame. The secondary barrier-buffer counter is represented by `Network.barBufs2` and its narrow accessors.
- `Abc_NtkAfterTrim` enforces the source assertions, uses `InputNumbers` for retained CI identity, maps the PI/PO and LI/LO suffixes in source order, sets each new latch to init-zero, duplicates terminal names, rebuilds the DFS AIG with buffer pass-through and AND nodes, and connects all COs in order. The C name/spec duplication is commented out, so this conversion leaves those fields unset.
- `Abc_NtkFromDarChoices` starts from the old interface, carries constraints/barrier metadata, clears graph scratch copies, maps constant/CIs, rebuilds all AND/XOR nodes in dependency order, attaches each equivalent node through `Object.Choice`, and connects the COs. Equivalence links are attached in a second pass because the Go graph's DFS dependency order does not promise that an alternative is visited before its representative. The C debug traversal is disabled (`if (0)`), so it has no Go behavior.
- `Abc_NtkFromDarSeq` uses a no-latch network start, maps the primary CI prefix and register-output suffix to PIs and BOs, creates init-zero latches, preserves the box-name pass, rebuilds reachable buffers/AND/XOR nodes, and reconnects POs and latch inputs by CO order. The Go AIG stores state explicitly in trailing CI/CO entries, so the C scratch-pointer loops over graph objects are expressed as explicit LO/LI register loops.

The direct tests cover sequential phase and terminal ordering, original CI/CO names after trim, choice linkage, and a real technology-mapped GIA round trip through the active MIO library. They pass in an isolated named-file harness. Full package execution is currently blocked by parser errors in other `base/abci` files.
