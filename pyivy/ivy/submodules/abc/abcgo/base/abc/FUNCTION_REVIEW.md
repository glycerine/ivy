# Functionality representation conversions

## Readability and compactness pass

Ported all active abcFunc.c routines, including the CUDD-enabled algorithms,
using the existing importable CUDD/core, Hop, DEC factoring and MIO engines.
The exact all-primes implementation lives in bdd/extrab/primes rather than
being approximated locally. SOP strings are Go-owned; the legacy allocation
argument is accepted where needed without manual memory management. Conversion
results are staged before replacing node data, so cube-limit failures retain the
original representation. Network.FunctionManager records the actual manager.

Local-AIG export helpers return the importable aig.Graph with explicit edges,
ordered terminals, register count, and LocalAIGMapping original-ID/cut metadata.
This replaces the original Gia_Man_t representation at the API boundary. AIG
hashing may share structurally identical gates; this is not the MF SAT-cost
export path. Hop scratch bindings use the owner's public accessors. Large local
BDDs use actual SYMM_SIFT plus transfer/permuted fanins, invoked explicitly
rather than relying on the C allocator's automatic reorder thresholds.

## Separate bug and fidelity pass

Exhaustive truth tests cover phase selection, negative SOPs, Hop roundtrip,
large-fanin reordering, mapped MIO conversion, direct-phase conversion, local-AIG
copies and graph export, constant reduction, and unchanged state on cube-limit
failure. Functional-isomorphism/evaluation consumers now accept the resulting
SOP/Hop/BDD/MIO data rather than losing prior functionality after conversion.

A source ABC CLI oracle under test_vectors checks exact normalized SOP rows and
fanin names after `bdd -s; sop`, independently generated by the original binary.
The primitives' owners additionally maintain their own CUDD/all-primes oracles.

Regressions found and fixed: paired ZDD cofactors take a literal-pair index,
not a variable number; the wrong index repeated the same absent branch. A
constant upper BDD bound now chooses a legal completion instead of returning
false for a nonzero lower bound. Constant reductions remove reciprocal fanouts,
not just truncate the fanin vector. Transparent barriers are excluded from SOP
sorting/normalization, avoiding attempts to parse nil barrier data. Temporary
BDD roots are dereferenced after transfer. Complemented bindings survive
local-AIG import/export and copied fanin edges.

Go GC owns manager storage. Callers must serialize mutations to shared managers,
consistent with their engine contracts. Arbitrary caller-supplied Go Boolean
functions require exact Shannon expansion; source SOPs use direct construction
and DEC factoring instead. The former source status-only SopToBlifMv placeholder
now invokes the real MV conversion already ported in abcBlifMv.go.

The entire previously ported ABC core plus function/SCL components passes
selected-file race tests and vet. Remaining original ABC files are visible;
full-package completion is not claimed.
